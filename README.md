# IntraMaps

IntraMaps is a "Google Maps" for the inside of buildings, starting with UFMG.

## Getting started

Requires Python 3.12 or newer.

```
python -m venv .venv
.venv\Scripts\Activate.ps1      # Windows (PowerShell)
source .venv/bin/activate       # Linux / macOS
pip install -e ".[dev]"
pytest
```
